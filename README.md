# ❧ Wild2 — A Tiny Wilderness Adventure

A compact, atmospheric browser **fantasy RPG** set in an original world — *The Greenwild*, the
last wild forest, whose life-giving Heartspring has fallen silent. No engine, no dependencies,
one self-contained `index.html`.

> Original setting and characters. (An earlier draft leaned on a well-known game's terms; this
> version is wholly original fantasy.)

## Play

- Choose your path: **Ranger, Wanderer, Scholar, or Guardian** — each shifts your starting stats.
- Track **Health, Stamina, Courage, and Supplies**.
- One compact quest: a forest trail, a danger at the ravine, a discovery at the Heartspring, and a final choice.
- **5 endings**. Progress **auto-saves** to localStorage; finish or restart any time.

## Run

```bash
start index.html        # Windows — or
python -m http.server 8000
```
